How to Generate PDF Invoices Automatically

Sep 2026 · 7 min read · pdfsnap

Manual invoice PDFs break at scale in the most predictable way: Stripe webhooks fire at 3am, subscriptions renew on the first of every month for thousands of customers simultaneously, and someone has to generate, attach, and send each one. The first time you write that code by hand it works. The tenth time you're debugging why the PDF attachment is empty for customers in timezone UTC+9.

Automating PDF invoices is a solved problem. The pattern is: trigger (webhook or scheduled event) → build HTML (your invoice template) → POST to pdfsnap → deliver (email attachment or download link). No headless browser, no Puppeteer cluster, no system dependencies. This guide walks through the full stack in Node.js and Python.

The Pattern

Every automated invoice pipeline has the same four stages:

  1. Trigger — a Stripe webhook event, a scheduled cron, or an API call from your billing service
  2. Build HTML — render your invoice template with customer data, line items, totals
  3. Convert to PDF — POST the HTML string to https://api.pdfsnap.dev/pdf
  4. Deliver — attach the PDF to an email via Nodemailer, or generate a signed download URL

Steps 1, 2, and 4 are standard backend code you already know how to write. Step 3 replaces the headless browser you'd otherwise have to manage.

Why not use Stripe's built-in invoices? Stripe's invoice PDFs are fine for simple billing. They break down when you need custom branding, multi-currency line items displayed in the customer's locale, tax breakdown rows specific to your jurisdiction, or any layout beyond Stripe's fixed template. If you've ever needed to match a client's invoice format exactly, you already know this.

Node.js: Full Working Example

1
Build the invoice HTML template

Keep the template as a plain JavaScript function that accepts invoice data and returns an HTML string. No template engine required — a tagged template literal is readable enough for invoices.

invoice-template.js
function buildInvoiceHtml(invoice) {
  const lineRows = invoice.lineItems.map(item => `
    <tr>
      <td>${item.description}</td>
      <td style="text-align:center">${item.qty}</td>
      <td style="text-align:right">$${item.unitPrice.toFixed(2)}</td>
      <td style="text-align:right">$${(item.qty * item.unitPrice).toFixed(2)}</td>
    </tr>
  `).join('');

  return `<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <style>
    body { font-family: 'Helvetica Neue', Arial, sans-serif; margin: 0; padding: 40px; color: #1a1a2e; font-size: 14px; }
    .header { display: flex; justify-content: space-between; align-items: flex-start; margin-bottom: 40px; }
    .logo { font-size: 22px; font-weight: 700; color: #1a1a2e; }
    .invoice-meta { text-align: right; color: #555; }
    .invoice-meta strong { color: #1a1a2e; }
    .parties { display: flex; gap: 48px; margin-bottom: 32px; }
    .party-block { flex: 1; }
    .party-label { font-size: 11px; text-transform: uppercase; letter-spacing: .08em; color: #888; margin-bottom: 6px; }
    table { width: 100%; border-collapse: collapse; margin-bottom: 24px; }
    thead th { background: #1a1a2e; color: #fff; padding: 10px 14px; text-align: left; font-size: 12px; text-transform: uppercase; letter-spacing: .05em; }
    thead th:not(:first-child) { text-align: right; }
    thead th:nth-child(2) { text-align: center; }
    tbody td { padding: 10px 14px; border-bottom: 1px solid #eee; }
    tbody td:not(:first-child) { text-align: right; }
    tbody td:nth-child(2) { text-align: center; }
    .totals { margin-left: auto; width: 280px; }
    .total-row { display: flex; justify-content: space-between; padding: 6px 0; color: #555; }
    .total-row.grand { font-weight: 700; font-size: 16px; color: #1a1a2e; border-top: 2px solid #1a1a2e; margin-top: 8px; padding-top: 12px; }
    .terms { margin-top: 40px; padding-top: 20px; border-top: 1px solid #eee; color: #888; font-size: 12px; }
    @page { size: A4; margin: 15mm 20mm; }
  </style>
</head>
<body>
  <div class="header">
    <div class="logo">${invoice.companyName}</div>
    <div class="invoice-meta">
      <div><strong>INVOICE</strong> #${invoice.invoiceNumber}</div>
      <div>Issued: ${invoice.issueDate}</div>
      <div>Due: ${invoice.dueDate}</div>
    </div>
  </div>

  <div class="parties">
    <div class="party-block">
      <div class="party-label">From</div>
      <div>${invoice.companyName}</div>
      <div>${invoice.companyAddress}</div>
      <div>${invoice.companyEmail}</div>
    </div>
    <div class="party-block">
      <div class="party-label">Bill To</div>
      <div><strong>${invoice.customerName}</strong></div>
      <div>${invoice.customerEmail}</div>
      <div>${invoice.customerAddress}</div>
    </div>
  </div>

  <table>
    <thead>
      <tr>
        <th>Description</th>
        <th>Qty</th>
        <th>Unit Price</th>
        <th>Amount</th>
      </tr>
    </thead>
    <tbody>${lineRows}</tbody>
  </table>

  <div class="totals">
    <div class="total-row"><span>Subtotal</span><span>$${invoice.subtotal.toFixed(2)}</span></div>
    <div class="total-row"><span>Tax (${invoice.taxRate}%)</span><span>$${invoice.taxAmount.toFixed(2)}</span></div>
    <div class="total-row grand"><span>Total Due</span><span>$${invoice.total.toFixed(2)}</span></div>
  </div>

  <div class="terms">
    Payment terms: ${invoice.paymentTerms}. Thank you for your business.
  </div>
</body>
</html>`;
}

module.exports = { buildInvoiceHtml };
2
Trigger from a Stripe webhook

The invoice.payment_succeeded event is the right trigger for sending a paid invoice PDF. It fires after a successful charge, meaning the customer has already been billed before you generate and send the document.

webhook.js (Express)
const express = require('express');
const stripe  = require('stripe')(process.env.STRIPE_SECRET_KEY);
const { buildInvoiceHtml } = require('./invoice-template');
const { convertAndDeliver } = require('./pdf-delivery');

const app = express();

// Use raw body for Stripe signature verification
app.post('/webhooks/stripe', express.raw({ type: 'application/json' }), async (req, res) => {
  const sig = req.headers['stripe-signature'];

  let event;
  try {
    event = stripe.webhooks.constructEvent(
      req.body,
      sig,
      process.env.STRIPE_WEBHOOK_SECRET
    );
  } catch (err) {
    console.error('Webhook signature verification failed:', err.message);
    return res.status(400).send(`Webhook Error: ${err.message}`);
  }

  if (event.type === 'invoice.payment_succeeded') {
    const stripeInvoice = event.data.object;

    // Build structured invoice data from Stripe payload
    const invoiceData = {
      invoiceNumber:   stripeInvoice.number,
      issueDate:       new Date(stripeInvoice.created * 1000).toLocaleDateString('en-US'),
      dueDate:         new Date(stripeInvoice.due_date * 1000).toLocaleDateString('en-US'),
      customerName:    stripeInvoice.customer_name,
      customerEmail:   stripeInvoice.customer_email,
      customerAddress: stripeInvoice.customer_address?.line1 ?? '',
      companyName:     process.env.COMPANY_NAME,
      companyAddress:  process.env.COMPANY_ADDRESS,
      companyEmail:    process.env.COMPANY_EMAIL,
      lineItems:       stripeInvoice.lines.data.map(line => ({
        description: line.description,
        qty:         line.quantity ?? 1,
        unitPrice:   (line.unit_amount_excluding_tax ?? line.amount) / 100,
      })),
      subtotal:      stripeInvoice.subtotal / 100,
      taxRate:       10, // adjust for your jurisdiction
      taxAmount:     stripeInvoice.tax / 100,
      total:         stripeInvoice.amount_due / 100,
      paymentTerms:  'Due on receipt',
    };

    // Fire-and-forget (use a queue in production)
    convertAndDeliver(invoiceData).catch(console.error);
  }

  res.json({ received: true });
});

app.listen(3000, () => console.log('Webhook server listening on :3000'));
3
Convert to PDF and deliver via email

POST the rendered HTML to pdfsnap, receive the PDF bytes, then attach them to an email with Nodemailer. The PDF never touches disk — the buffer goes straight from pdfsnap into the email attachment.

pdf-delivery.js
const nodemailer = require('nodemailer');
const { buildInvoiceHtml } = require('./invoice-template');

const transporter = nodemailer.createTransport({
  host:   process.env.SMTP_HOST,
  port:   587,
  secure: false,
  auth: {
    user: process.env.SMTP_USER,
    pass: process.env.SMTP_PASS,
  },
});

async function convertAndDeliver(invoiceData) {
  // Step 1: render HTML
  const html = buildInvoiceHtml(invoiceData);

  // Step 2: convert via pdfsnap
  const pdfRes = await fetch('https://api.pdfsnap.dev/pdf', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${process.env.PDFSNAP_KEY}`,
      'Content-Type':  'application/json',
    },
    body: JSON.stringify({
      html,
      options: {
        format:          'A4',
        printBackground: true,
        margin: { top: '15mm', right: '20mm', bottom: '15mm', left: '20mm' },
      },
    }),
  });

  if (!pdfRes.ok) {
    throw new Error(`pdfsnap error ${pdfRes.status}: ${await pdfRes.text()}`);
  }

  const pdfBuffer = Buffer.from(await pdfRes.arrayBuffer());
  const filename  = `invoice-${invoiceData.invoiceNumber}.pdf`;

  // Step 3: send via Nodemailer
  await transporter.sendMail({
    from:    `"${invoiceData.companyName}" <${invoiceData.companyEmail}>`,
    to:      invoiceData.customerEmail,
    subject: `Invoice #${invoiceData.invoiceNumber} — ${invoiceData.companyName}`,
    text:    `Hi ${invoiceData.customerName},\n\nThank you for your payment. Your invoice is attached.\n\nTotal paid: $${invoiceData.total.toFixed(2)}\n\nBest,\n${invoiceData.companyName}`,
    html:    `<p>Hi ${invoiceData.customerName},</p><p>Thank you for your payment. Your invoice is attached.</p><p><strong>Total paid: $${invoiceData.total.toFixed(2)}</strong></p>`,
    attachments: [
      {
        filename,
        content:     pdfBuffer,
        contentType: 'application/pdf',
      },
    ],
  });

  console.log(`Invoice ${invoiceData.invoiceNumber} sent to ${invoiceData.customerEmail}`);
}

module.exports = { convertAndDeliver };

Python / Django Version

The same three-step pattern maps directly to Python. Here's a compact Django view that generates and emails a PDF invoice when called from a Celery task or webhook handler:

invoices/tasks.py (Django + Celery)
import requests
from django.template.loader import render_to_string
from django.core.mail import EmailMessage
from celery import shared_task


@shared_task
def send_invoice_pdf(invoice_id):
    from .models import Invoice  # avoid circular import

    invoice = Invoice.objects.select_related('customer').get(pk=invoice_id)

    # Step 1: render HTML from a Django template
    html = render_to_string('invoices/pdf_template.html', {
        'invoice':  invoice,
        'customer': invoice.customer,
    })

    # Step 2: convert via pdfsnap
    resp = requests.post(
        'https://api.pdfsnap.dev/pdf',
        headers={'Authorization': f'Bearer {settings.PDFSNAP_KEY}'},
        json={
            'html':    html,
            'options': {'format': 'A4', 'printBackground': True},
        },
        timeout=30,
    )
    resp.raise_for_status()

    # Step 3: attach and email
    email = EmailMessage(
        subject=f'Invoice #{invoice.number} — {settings.COMPANY_NAME}',
        body=f'Hi {invoice.customer.name},\n\nYour invoice is attached. Total: ${invoice.total}\n\nThank you.',
        from_email=settings.DEFAULT_FROM_EMAIL,
        to=[invoice.customer.email],
    )
    email.attach(
        f'invoice-{invoice.number}.pdf',
        resp.content,
        'application/pdf',
    )
    email.send()
    return f'Sent invoice {invoice.number} to {invoice.customer.email}'

Scheduling for Recurring Invoices

Subscription billing means invoices generate on a predictable schedule. Rather than relying solely on Stripe webhooks (which can fail silently if your server is down), also run a monthly cron that catches anything that slipped through:

scheduler.js (node-cron)
const cron = require('node-cron'); const { generateMonthlyInvoices } = require('./billing'); // Run at 06:00 UTC on the 1st of every month cron.schedule('0 6 1 * *', async () => { console.log('[cron] Generating monthly invoices...'); try { const results = await generateMonthlyInvoices(); console.log(`[cron] Done. Generated ${results.count} invoices, ${results.errors} errors.`); } catch (err) { console.error('[cron] Fatal error in invoice generation:', err); // Alert your on-call channel here } }, { scheduled: true, timezone: 'UTC', }); async function generateMonthlyInvoices() { // Fetch all active subscriptions due this month const subscriptions = await db.subscriptions.findMany({ where: { status: 'active', billing_day: new Date().getDate(), }, }); let count = 0, errors = 0; for (const sub of subscriptions) { try { const invoiceData = await buildInvoiceDataFromSubscription(sub); await convertAndDeliver(invoiceData); await db.invoices.create({ data: { ...invoiceData, sentAt: new Date() } }); count++; } catch (err) { console.error(`Failed for subscription ${sub.id}:`, err.message); errors++; } } return { count, errors }; }

Idempotency matters: Before generating, check whether an invoice for this customer and billing period already exists in your database. Stripe webhooks can fire more than once for the same event. A unique constraint on (customer_id, billing_period) in your invoices table is the simplest guard against duplicate sends.

Summary

Automated PDF invoicing boils down to three things you already know how to build, plus one API call:

  • Trigger: Stripe's invoice.payment_succeeded event or a monthly cron
  • Template: a plain JavaScript or Python function that returns an HTML string — no special renderer required
  • Convert: one POST to api.pdfsnap.dev/pdf returns PDF bytes; no Puppeteer, no Docker layer
  • Deliver: Nodemailer (Node.js) or Django's EmailMessage attaches the buffer directly
  • Guard idempotency: check for existing invoices before generating to prevent duplicate sends
  • Schedule a safety net: a monthly cron catches anything the webhook missed
