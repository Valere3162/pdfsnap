How it works

URL or HTML in. PDF out.

01
Send a POST request

Pass a URL to capture or raw HTML to render. Include your API key as a Bearer token.

POST /api/pdf { "url": "...", "format": "A4" }
02
Chromium renders it

A headless Chromium instance processes your page — full CSS, webfonts, images, and print media queries.

← application/pdf (binary stream)
03
Serve or store the PDF

Stream directly to the browser, save to S3, or email as an attachment. No temp files, no polling.

res.pipe(fs.createWriteStream('out.pdf'))
Integration

cURL to PDF
in 30 seconds

No SDK. No dependencies. A single POST request returns a binary PDF stream — pipe it wherever you need it. Works from any language or HTTP client.

SHELL 
curl -X POST https://pdfsnap.dev/api/pdf \
  -H "Authorization: Bearer sk_your_key" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com","format":"A4"}' \
  --output output.pdf

# Response: binary PDF stream
# Content-Type: application/pdf
# x-pdfsnap-pages: 3
# x-pdfsnap-ms: 1204
