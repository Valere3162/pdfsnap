pdfsnap API

Convert any URL or raw HTML to a pixel-perfect PDF via a single POST request. Powered by Chromium. No servers to manage.

Authentication

All requests require a Bearer token in the Authorization header. API keys start with sk_ for secret keys. 

# Pass your API key as a Bearer token
Authorization: Bearer sk_your_api_key_here
⚠ Keep your API key secret. Never expose it in client-side code or public repositories. If compromised, generate a new key immediately.

Base URL

All API endpoints are served from:

https://pdfsnap.dev

Rate Limits

Limits are per API key, per calendar month (UTC). Limits reset on the 1st of each month. The current usage tier is returned in every response as x-pdfsnap-remaining.

Tier PDFs / month Max body size HTML input
Free 25 500 KB URL only
Pro 500 2 MB Yes
Business 5,000 2 MB Yes

POST /api/pdf

Convert a URL or raw HTML string to a PDF document. Returns a binary PDF stream.

POST /api/pdf Convert to PDF

Request body must be application/json. Either url or html is required. On success, returns application/pdf binary.

Request body parameters

ParameterTypeDescription
url required* string Full URL to render. Must be publicly accessible. Available on all tiers.
html Pro+ string Raw HTML string to render. Overrides url if both provided. Max 2 MB. Pro and Business tiers only.
format optional string Page format: "A4" (default), "Letter", "A3", "Legal".
orientation optional string "portrait" (default) or "landscape".
margin optional object CSS-style margin object: { "top": "20mm", "right": "15mm", "bottom": "20mm", "left": "15mm" }. Defaults to 10mm all sides.
scale optional number Page scale factor from 0.1 to 2.0. Default: 1.0.
background optional boolean Print CSS background colors and images. Default: true.
waitFor optional string Wait strategy before capturing: "load" (default), "networkidle", or a CSS selector to wait for.

Example request

curl -X POST https://pdfsnap.dev/api/pdf \
  -H "Authorization: Bearer sk_your_key" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com","format":"A4","orientation":"portrait"}' \
  --output example.pdf

HTML input example (Pro+)

curl -X POST https://pdfsnap.dev/api/pdf \
  -H "Authorization: Bearer sk_your_key" \
  -H "Content-Type: application/json" \
  -d '{"html":"<h1>Invoice #1042</h1><p>Due: Dec 1</p>","format":"Letter"}' \
  --output invoice.pdf

Node.js example

// Using native fetch (Node 18+)
const res = await fetch('https://pdfsnap.dev/api/pdf', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${process.env.PDFSNAP_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    url: 'https://yourapp.com/invoice/1042',
    format: 'A4',
    waitFor: 'networkidle',
  }),
});

// Stream to file
const buffer = await res.arrayBuffer();
await fs.writeFile('invoice.pdf', Buffer.from(buffer));

Python example

import requests, os

resp = requests.post(
    "https://pdfsnap.dev/api/pdf",
    headers={
        "Authorization": f"Bearer {os.environ['PDFSNAP_KEY']}",
        "Content-Type": "application/json",
    },
    json={"url": "https://example.com", "format": "A4"},
)

with open("output.pdf", "wb") as f:
    f.write(resp.content)

Response headers

HeaderDescription
x-pdfsnap-pages Number of pages in the generated PDF.
x-pdfsnap-ms Server-side render time in milliseconds.
x-pdfsnap-remaining Conversions remaining this month on your tier.
Content-Type application/pdf
Content-Disposition attachment; filename="output.pdf"

GET /api/usage

Returns current usage stats for the authenticated API key.

GET /api/usage Query usage

No request body needed. Returns JSON usage object.

Example request

curl https://pdfsnap.dev/api/usage \
  -H "Authorization: Bearer sk_your_key"

Example response

{
  "tier": "pro",
  "used": 47,
  "limit": 500,
  "remaining": 453,
  "reset_at": "2026-10-01T00:00:00Z"
}

GET /api/health

Returns the operational status of the API. Safe to poll from uptime monitors — no authentication required.

GET /api/health Health check

No authentication required. Returns 200 when all systems are operational, 503 when degraded.

200 OK response

Page Formats

The format parameter accepts the following values:

ValueDimensionsCommon use
A4210 × 297 mmInternational standard, default
Letter216 × 279 mmUS standard
A3297 × 420 mmWide reports, spreadsheets
Legal216 × 356 mmUS legal documents

Pair format with orientation: "landscape" to flip dimensions. For example, A4 landscape = 297 × 210 mm.

Error Codes

StatusCodeDescription
200 — PDF generated successfully.
400 invalid_input Missing url or html, or malformed JSON body.
401 invalid_key Bearer token is missing, malformed, or expired.
403 tier_restricted Feature requires a higher tier (e.g. HTML input on Free tier).
413 body_too_large HTML body exceeds allowed size for your tier (500KB free, 2MB paid).
429 rate_limited Monthly quota exceeded. Resets 1st of next month UTC.
500 render_error Chromium failed to render. Retry with backoff. Check URL accessibility.
504 timeout Page took longer than 30s to load. Try a shorter waitFor strategy.

Error body format

{
  "error": "HTML input requires a Pro or Business plan.",
  "code": "tier_restricted",
  "upgrade_url": "https://pdfsnap.dev/#pricing"
}
